What this page is

The complete, replayable record of one agent playing one ARC-AGI-3 game. The agent can't read the rules — it plays by writing a world model (a program that predicts the next frame), keeping that model consistent with everything observed, planning inside it, and letting reality veto it: the moment a real frame disagrees with the model's prediction, the plan is cancelled and the model gets fixed.

Start on the Now tab

It answers the two questions that matter: (a) how much of the observed history the current model explains — one row per attempt at a level (attempts end cleared, died, or abandoned; failed attempts count as evidence too), with a green/red bar per transition — and (b) the best current plan and how far it got.

The main controls (left side)

  • Slider / ←→ — step through real time: every action the agent actually took. The big grid is the game screen after that action; diff outlines the cells the action changed; a gold crosshair marks where the agent clicked.
  • Tick strip — one tick per action: normal, level cleared, death, win, red dot = the model mispredicted here. The dropdown beside it swaps this for a model version's report card: pick a version and every tick shows whether that version explains that transition (yes no skipped).
  • Turn rail (numbered chips) — the agent's thinking cycles. Each chip is one observe→think→act round; dashed = a round of pure thinking (no real actions). Click a chip to pin its details in the right-hand tabs.
  • Purple = imagination. "▶ simulate" buttons replay a plan inside the model the agent had at that moment. The border turns purple and the arrows scrub predicted frames; the caption says whether each one matched reality or was never executed. esc exits.

The tabs (right side)

  • Turn — the plan committed in this thinking cycle, the agent's stated reason, and which step of it you're on.
  • Meta-actions — what the agent did between actions, in order: model checks (backtest), planning searches (bfs), with their outputs.
  • Model code — the world model's source as of the current moment, plus what changed in its latest edit.
  • Notes — the agent's own scratchpad at that moment.
  • Mispredicts — every point where reality contradicted the model, with predicted-vs-actual frames side by side. These moments are the engine of the whole method.
